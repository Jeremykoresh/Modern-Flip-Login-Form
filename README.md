# 🔥 Modern Flip Login Form

A modern login and signup form with a smooth flip animation effect.  
Built using HTML, CSS, and JavaScript with a clean, responsive, and minimal design.

---

## ✨ Features
- Smooth flip animation between Login & Sign Up
- Modern glassmorphism UI design
- Fully responsive (mobile & desktop)
- Clean and readable code structure
- Beginner-friendly and easy to customize
